## How ML and the website interact

### 1. Training (offline)

- **Crop model**  
  `train_model.py` reads `dataset/Crop_recommendation.csv`, trains a **Decision Tree** on features `N, P, K, temperature, humidity, ph, rainfall`, and saves:
  - `crop_model.pkl` – trained classifier  
  - `scaler.pkl` – StandardScaler (same scaling used at prediction time)  
  - `crop_labels.pkl` – dict mapping class index → crop name (e.g. `0 → 'rice'`)  
  - `accuracy.pkl` – float accuracy for display  

- **Fertilizer model**  
  `train_fertilizer_model.py` reads `dataset/Fertilizer Prediction.csv`, trains a **Random Forest** on encoded Soil Type, Crop Type, and numeric features, and saves:
  - `fertilizer_model.pkl` – trained classifier  
  - `soil_encoder.pkl` – LabelEncoder for Soil Type (Black, Clayey, Loamy, Red, Sandy)  
  - `fertilizer_crop_encoder.pkl` – LabelEncoder for Crop Type (Paddy, Maize, Pulses, etc.)  
  - `fertilizer_encoder.pkl` – LabelEncoder for Fertilizer Name (decode prediction to name)  

### 2. Prediction flow on the website

**Crop prediction (form or chatbot):**

1. User input: `N, P, K, temperature, humidity, ph, rainfall` (weather can come from API).  
2. **Scale:** `scaler.transform([[N, P, K, temp, hum, ph, rain]])`  
3. **Model:** `crop_model.predict(scaled_features)` → integer class (e.g. `0`)  
4. **Decode:** `crop_labels[prediction[0]]` → crop name (e.g. `'rice'`)  
5. Show crop name on result page or in chatbot.

**Fertilizer prediction (main form only):**

1. Use the **crop name** from the crop model (e.g. `'rice'`).  
2. **Map** to fertilizer Crop Type: `CROP_TO_FERTILIZER_CROP_TYPE['rice']` → `'Paddy'`.  
3. **Encode:**  
   - `soil_encoder.transform([soil_type])`  
   - `fertilizer_crop_encoder.transform([fert_crop_type])`  
4. **Model:** Build feature vector `[temp, hum, moisture, soil_enc, crop_enc, N, K, P]` and run `fertilizer_model.predict(...)`.  
5. **Decode:** `fertilizer_encoder.inverse_transform(pred)` → fertilizer name.  
6. Show fertilizer name on result page.

### 3. Summary

| Step        | Crop pipeline                          | Fertilizer pipeline                                      |
|------------|----------------------------------------|----------------------------------------------------------|
| Input      | N, P, K, temp, hum, ph, rain          | temp, hum, moisture, soil_type, crop_name → Crop Type    |
| Preprocess | StandardScaler (scaler.pkl)           | LabelEncoders (soil, fertilizer_crop)                    |
| Model      | Decision Tree (crop_model.pkl)         | Random Forest (fertilizer_model.pkl)                    |
| Decode     | crop_labels.pkl (index → name)         | fertilizer_encoder.pkl (index → fertilizer name)        |

The website (App.py) loads all `.pkl` files once at startup and uses them for every prediction request.
